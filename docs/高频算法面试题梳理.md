# 一、排序

## 1.1 快速排序

| 维度 | 内容 |
|------|------|
| 题型 | 排序 - 分治 |
| 频度 | ⭐⭐⭐ 高频（手写排序必考） |
| 难度 | 🔥🔥 中等 |

**核心思路：**
选一个基准元素(pivot)，将数组分为左右两部分：左边 < pivot，右边 > pivot，然后递归排序左右两部分。

**类型特征：**
- 分治思想的典型应用
- 递归 + partition 操作
- 原地排序版本更优（不额外申请数组）

**关键代码骨架：**
```js
const quickSort = (arr) => {
  const _partition = (left, right) => {
    const pivotVal = arr[Math.floor(left + (right - left) / 2)];
    while (left < right) {
      while (left < right && arr[left] < pivotVal) left++;
      while (left < right && arr[right] > pivotVal) right--;
      if (left < right) { _swap(left, right); left++; right--; }
    }
    return left;
  }
  const _sort = (left, right) => {
    if (right <= left) return;
    const pivotIndex = _partition(left, right);
    _sort(left, pivotIndex);
    _sort(pivotIndex + 1, right);
  }
  _sort(0, arr.length - 1);
  return arr;
}
```

**注意点：**
1. 时间复杂度 O(nlogN)，最坏 O(n²)（完全有序时退化为冒泡）
2. 空间复杂度 O(logN)（递归栈深度）
3. 不稳定排序
4. 优化：随机选取 pivot 避免最坏情况；三数取中法

## 1.2 归并排序

| 维度 | 内容 |
|------|------|
| 题型 | 排序 - 分治 |
| 频度 | ⭐⭐ 中频 |
| 难度 | 🔥🔥 中等 |

**核心思路：**
将数组不断二分，直到每个子数组只有一个元素，然后两两合并（merge）有序子数组。

**类型特征：**
- 分治 + 合并操作
- 稳定排序（快排不稳定时的替代方案）
- 需要额外空间 O(n)

**关键代码骨架：**
```js
const mergeSort = (arr) => {
  if (arr.length <= 1) return arr;
  const mid = Math.floor(arr.length / 2);
  const left = mergeSort(arr.slice(0, mid));
  const right = mergeSort(arr.slice(mid));
  return merge(left, right);
}
const merge = (left, right) => {
  const res = [];
  let i = 0, j = 0;
  while (i < left.length && j < right.length) {
    res.push(left[i] <= right[j] ? left[i++] : right[j++]);
  }
  return res.concat(left.slice(i)).concat(right.slice(j));
}
```

**注意点：**
1. 时间复杂度稳定 O(nlogN)，不会退化
2. 空间复杂度 O(n)（需要临时数组）
3. 稳定排序，适合对稳定性有要求的场景
4. 归并的 merge 操作和「合并两个有序链表/数组」是同一个思路

# 二、数组

## 2.1 双指针

### 26-删除有序数组中的重复项

| 维度 | 内容 |
|------|------|
| 题型 | 双指针 - 快慢指针 - 原地去重 |
| 频度 | ⭐⭐ 中频 |
| 难度 | 🔥 简单 |

**核心思路：**
快慢指针，slow 指向去重后数组的末尾，fast 遍历数组。当 `nums[fast] !== nums[slow]` 时，slow++，将 fast 的值覆盖到 slow 位置。

**类型特征：** 有序数组原地操作，不能使用额外空间

**注意点：**
1. 数组已排序是前提，相同元素相邻
2. 返回的是去重后的长度 slow + 1
3. 同思路题：83-删除排序链表中的重复元素

### 27-移除元素

| 维度 | 内容 |
|------|------|
| 题型 | 双指针 - 快慢指针 - 原地移除 |
| 频度 | ⭐⭐ 中频 |
| 难度 | 🔥 简单 |

**核心思路：**
快慢指针，fast 遍历数组，遇到不等于 val 的元素就写入 slow 位置，slow++。

**类型特征：** 原地移除指定值，不关心顺序

**注意点：**
1. 和26题思路一致，区别是判断条件不同
2. 同思路：283-移动零（把0移到末尾）

### 88-合并两个有序数组

| 维度 | 内容 |
|------|------|
| 题型 | 双指针 - 逆向双指针 |
| 频度 | ⭐⭐⭐ 高频 |
| 难度 | 🔥 简单 |

**核心思路：**
从后往前遍历，用三个指针：p1 指向 nums1 有效末尾，p2 指向 nums2 末尾，p 指向 nums1 总末尾。每次取较大值放到 p 位置。

**类型特征：** 两个有序序列合并，原地操作

**注意点：**
1. 从后往前填充，避免覆盖 nums1 中未处理的元素
2. 同思路：21-合并两个有序链表（正向双指针）
3. 归并排序的 merge 步骤本质相同

### 15-三数之和

| 维度 | 内容 |
|------|------|
| 题型 | 双指针 - 排序 + 固定一个数 + 左右指针 |
| 频度 | ⭐⭐⭐ 高频 |
| 难度 | 🔥🔥 中等 |

**核心思路：**
先排序，外层循环固定第一个数 a，内层用左右双指针找 b + c = -a。将 O(n³) 降为 O(n²)。

**类型特征：** N数之和系列，排序 + 双指针是标准解法

**注意点：**
1. 去重是关键：外层 `nums[i] === nums[i-1]` 时 continue；内层找到解后左右指针都要跳过重复值
2. 排序后第一个数 > 0 可以直接 break
3. 同系列：18-四数之和（多一层循环）

## 2.2 滑动窗口

> 滑动窗口本质是双指针的特例，用于动态遍历子串/子数组。常见题目：找满足某一条件的最长/最短子数组/子串。

### 209-长度最小的子数组

| 维度 | 内容 |
|------|------|
| 题型 | 滑动窗口 - 最短子数组 |
| 频度 | ⭐⭐ 中频 |
| 难度 | 🔥🔥 中等 |

**核心思路：**
right 不断扩大窗口累加 sum，当 sum >= target 时，尝试缩小窗口（left++），记录最小长度。

**类型特征：** 求满足条件的最短连续子数组

**注意点：**
1. 窗口内维护的是连续子数组的和
2. 缩小窗口时要持续缩小直到不满足条件
3. 初始 minLen 设为 Infinity，最后判断是否更新过

### 3-无重复字符的最长子串

| 维度 | 内容 |
|------|------|
| 题型 | 滑动窗口 - 最长子串 |
| 频度 | ⭐⭐⭐ 高频（超高频面试题） |
| 难度 | 🔥🔥🔥 困难 |

**核心思路：**
维护一个 `windowChar2CountMap`（字符->出现次数），right 扩大窗口时将字符计数+1，当某字符计数 > 1 时，left 缩小窗口直到无重复，不断刷新 maxLen。

**关键代码骨架：**
```js
var lengthOfLongestSubstring = function(s) {
  let res = 0, left = 0, right = 0;
  const map = new Map();
  while (right < s.length) {
    const willIn = s[right];
    map.set(willIn, (map.get(willIn) || 0) + 1);
    while (map.get(willIn) > 1) {
      const willOut = s[left];
      left++;
      map.set(willOut, map.get(willOut) - 1);
    }
    res = Math.max(res, right - left + 1);
    right++;
  }
  return res;
};
```

**注意点：**
1. 滑动窗口的核心组件：left, right, willInChar, willOutChar, charCountMap
2. right 先行扩大窗口 → 条件不满足时 left 缩小 → 刷新最值
3. 同类型：567-字符串的排列、76-最小覆盖子串

## 2.4 随机算法

### 数组乱序-洗牌算法

| 维度 | 内容 |
|------|------|
| 题型 | 随机算法 - Fisher-Yates 洗牌 |
| 频度 | ⭐⭐ 中频 |
| 难度 | 🔥 简单 |

**核心思路：**
从后往前遍历，在 [0, i] 范围内随机生成一个 index，交换 arr[i] 和 arr[index]。

**关键代码骨架：**
```js
function shuffle(arr) {
  for (let i = arr.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [arr[i], arr[j]] = [arr[j], arr[i]];
  }
  return arr;
}
```

**注意点：**
1. 保证每个元素出现在每个位置的概率相等
2. 时间 O(n)，空间 O(1)
3. 面试常考：为什么不能用 `sort(() => Math.random() - 0.5)`？因为概率不均匀

### 347-前K个高频元素

| 维度 | 内容 |
|------|------|
| 题型 | 优先级队列（小顶堆）+ HashMap |
| 频度 | ⭐⭐⭐ 高频 |

**核心思路：**

### 215-数组中的第K个最大元素（TopK）

| 维度 | 内容 |
|------|------|
| 题型 | 优先级队列（小顶堆）/ 快速选择 |
| 频度 | ⭐⭐⭐ 高频（超高频面试题） |
| 难度 | 🔥🔥🔥 困难 |

**核心思路：**
维护一个大小为 k 的小顶堆，遍历数组，堆满后每次 push 新元素并 pop 堆顶（最小值），最终堆顶就是第 K 大。

**关键代码骨架：**
```js
// 小顶堆核心操作
// push: 队尾插入 → floatUp（上浮）
// pop:  返回队头 → 队尾拉到队头 → floatDown（下沉）
// 父子关系: parent = floor((i-1)/2), left = 2i+1, right = 2i+2

var findKthLargest = function(nums, k) {
  const minHeap = new PriorityQueue();
  for (const num of nums) {
    minHeap.push(num);
    if (minHeap.size() > k) minHeap.pop();
  }
  return minHeap.peak();
};
```

**注意点：**
1. 必须掌握小顶堆的手写实现（floatUp + floatDown + swap）
2. 堆的核心：数组存储的完全二叉树，父子下标关系
3. 时间复杂度 O(nlogk)，空间 O(k)
4. 另一种解法：快速选择算法（基于 partition），平均 O(n)

# 五、链表

> 链表核心要素：虚拟头结点(dummy)防边界错误、指针操作需要画图模拟、查找类不需要 dummy，操作类需要 dummy

### 206-反转链表

| 维度 | 内容 |
|------|------|
| 题型 | 链表 - 反转 - 双指针迭代 / 递归 |
| 频度 | ⭐⭐⭐ 高频（链表必考题） |
| 难度 | 🔥 简单 |

**核心思路：**

方法1 - 迭代法（推荐）：三个指针 pre=null, cur=head, temp。每次将 cur.next 指向 pre，然后三个指针同步前进。
```js
var reverseList = function(head) {
  let pre = null, cur = head, temp = null;
  while (cur !== null) {
    temp = cur.next;
    cur.next = pre;
    pre = cur;
    cur = temp;
  }
  return pre;
};
```

方法2 - 递归法：递归到链表末尾，回溯时反转指针。
```js
var reverseList = function(head) {
  if (!head || !head.next) return head;
  const last = reverseList(head.next);
  head.next.next = head;
  head.next = null;
  return last;
};
```

**注意点：**
1. 迭代法：pre 初始为 null（反转后的尾节点指向 null）
2. 递归法：空间 O(n)，理解递归定义比跳入细节更重要
3. 是 92-反转链表II、24-两两交换 等题的基础

### 92-反转链表II

| 维度 | 内容 |
|------|------|
| 题型 | 链表 - 区间反转 |
| 频度 | ⭐⭐⭐ 高频 |
| 难度 | 🔥🔥 中等 |

**核心思路：**
找到反转区间的前驱节点，对区间内的节点执行反转，然后重新连接前驱和后继。

**注意点：**

### 102-二叉树的层序遍历

| 维度 | 内容 |
|------|------|
| 题型 | 二叉树 - BFS - 队列 |
| 频度 | ⭐⭐⭐ 高频 |
| 难度 | 🔥🔥 中等 |

**核心思路：**
用队列实现 BFS，每次处理一层：记录当前层的 size，循环 size 次出队处理，同时将子节点入队。

**关键代码骨架：**
```js
var levelOrder = function(root) {
  if (!root) return [];
  const result = [], queue = [root];
  while (queue.length) {
    const layerSize = queue.length;
    const layerArr = [];
    for (let i = 0; i < layerSize; i++) {
      const node = queue.shift();
      layerArr.push(node.val);
      if (node.left) queue.push(node.left);
      if (node.right) queue.push(node.right);
    }
    result.push(layerArr);
  }
  return result;
};
```

**注意点：**
1. 关键：用 layerSize 控制每层的遍历范围
2. 变种：多叉树层序遍历、每层节点之和
3. BFS 模板是很多题的基础：111-最小深度、116-填充右侧指针等

```js
// 序列化
const serialize = (root) => {
  if (!root) return '#,';

};
// 反序列化
const deserialize = (data) => {
  const nodes = data.split(',');
  const build = () => {
    const val = nodes.shift();
    if (val === '#') return null;
    const node = new TreeNode(+val);
    node.left = build();
    node.right = build();
    return node;
  };
  return build();
};
```

### 236-二叉树的最近公共祖先

| 维度 | 内容 |
|------|------|
| 题型 | 二叉树 - 后序遍历 - 回溯 |
| 频度 | ⭐⭐⭐ 高频 |
| 难度 | 🔥🔥🔥 困难 |

**核心思路：**
后序遍历（自底向上回溯）：
- base case：root 为 null 或等于 p/q，返回 root
- 递归获取左右子树结果 left、right
- 如果 left 和 right 都不为 null → 当前 root 就是 LCA
- 只有一边不为 null → 返回那一边

**关键代码骨架：**
```js
var lowestCommonAncestor = function(root, p, q) {
  if (!root || root === p || root === q) return root;
  const left = lowestCommonAncestor(root.left, p, q);
  const right = lowestCommonAncestor(root.right, p, q);
  if (left && right) return root;
  return left || right;
};
```

**注意点：**
1. 本质是后序遍历：先处理左右子树，再处理当前节点
2. 返回值的含义：该子树中是否包含 p 或 q
3. 类比 git rebase 的原理：找到两个分支的公共祖先

# 七、DFS回溯

> 回溯模板：DFS枚举 + 判断收集条件 + 去重
> 排列：usedArray 去重 | 组合：startIndex 去重 | 子集/分割：本质是组合

### 46-全排列

| 维度 | 内容 |
|------|------|
| 题型 | DFS回溯 - 排列 |
| 频度 | ⭐⭐⭐ 高频（回溯必考题） |
| 难度 | 🔥🔥 中等 |

**核心思路：**
DFS 遍历决策树，用 usedArray 标记已选择的元素。path 长度等于 nums 长度时收集结果。

**关键代码骨架：**
```js
var permute = function(nums) {
  const res = [];
  function dfs(path, usedArray) {
    if (path.length === nums.length) {
      res.push(path.slice()); // 必须拷贝
      return;
    }
    for (let i = 0; i < nums.length; i++) {
      if (usedArray[i]) continue;
      path.push(nums[i]);
      usedArray[i] = true;
      dfs(path, usedArray);
      path.pop();          // 撤销选择
      usedArray[i] = false; // 撤销标记
    }
  }
  dfs([], []);
  return res;
};
```

**注意点：**
1. res.push(path.slice()) 必须拷贝，否则引用会被后续操作污染
2. 排列 vs 组合的区别：排列用 usedArray，组合用 startIndex
3. 47-全排列II（有重复元素）：排序 + `nums[i] === nums[i-1] && !used[i-1]` 去重
4. 回溯三要素：选择列表、路径、结束条件

## 8.2 子序列

### 53-最大子数组和

| 维度 | 内容 |
|------|------|
| 题型 | DP - 连续子序列 - 最大和 |
| 频度 | ⭐⭐⭐ 高频 |
| 难度 | 🔥🔥 中等 |

**核心思路：**

方法1 - DP：
- dp[i]：以第 i 个元素结尾的子数组的最大和
- 转移方程：`dp[i] = Math.max(dp[i-1] + nums[i], nums[i])`
  - 要么加入前面的子数组，要么从当前元素重新开始

```js
var maxSubArray = function(nums) {
  let curSum = nums[0], maxSum = curSum;
  for (let i = 1; i < nums.length; i++) {
    curSum = curSum < 0 ? nums[i] : curSum + nums[i];
    maxSum = Math.max(maxSum, curSum);
  }
  return maxSum;
};
```

**注意点：**
1. dp[0] = nums[0]，最大和不一定是正数
2. 贪心解法也可以：curSum < 0 时重置为当前元素
3. 也可以用分治法解决（面试较少考）

# 九、单调栈

### 42-接雨水

| 维度 | 内容 |
|------|------|
| 题型 | 单调栈 / DP / 双指针 |
| 频度 | ⭐⭐⭐ 高频（经典 hard 题） |
| 难度 | 🔥🔥🔥 困难 |

**核心思路：**

方法1 - DP（推荐理解）：
- 构建 leftMaxHeight[i]：i 左侧（含自身）最高柱子
- 构建 rightMaxHeight[i]：i 右侧（含自身）最高柱子
- 每个柱子能接的雨水：`min(leftMax[i], rightMax[i]) - height[i]`

```js
var trap = function(height) {
  const n = height.length;
  if (n < 3) return 0;
  const leftMax = [...height], rightMax = [...height];
  for (let i = 1; i < n; i++) leftMax[i] = Math.max(leftMax[i-1], height[i]);
  for (let i = n-2; i >= 0; i--) rightMax[i] = Math.max(rightMax[i+1], height[i]);
  let res = 0;
  for (let i = 0; i < n; i++) {
    const h = Math.min(leftMax[i], rightMax[i]) - height[i];
    if (h > 0) res += h;
  }
  return res;
};
```

方法2 - 单调栈：单调递增栈，遇到更高柱子时出栈计算凹槽面积（按行计算）

方法3 - 双指针：O(1) 空间，左右指针向内逼近

**注意点：**
1. DP 法最好理解：用空间换时间，避免每个柱子都向两边找最高
2. 单调栈按行计算，DP/双指针按列计算
3. 至少掌握一种方法，推荐 DP 法
4. 同类型：84-柱状图中最大的矩形

# 十、数据结构设计

### 146-LRU缓存

| 维度 | 内容 |
|------|------|
| 题型 | 数据结构设计 - 缓存淘汰 |
| 频度 | ⭐⭐⭐ 高频（超高频面试题） |
| 难度 | 🔥🔥🔥 困难 |

**核心思路：**
利用 Map 的有序性（插入顺序）：队头最旧，队尾最新。

算法骨架：
- get(key)：存在则 addRecently(key) 并返回值，不存在返回 -1
- put(key, val)：
  - 已存在：addRecently(key, val)
  - 不存在：判满 → 满则删除队头（最久未访问）→ set(key, val)
- addRecently(key, val)：delete(key) → set(key, val)（提升到队尾）

**关键代码骨架：**
```js
var LRUCache = function(capacity) {
  this.cache = new Map();
  this.capacity = capacity;
};
LRUCache.prototype.get = function(key) {
  if (!this.cache.has(key)) return -1;
  const val = this.cache.get(key);
  this.cache.delete(key);
  this.cache.set(key, val); // 提升到最新
  return val;
};
LRUCache.prototype.put = function(key, value) {
  if (this.cache.has(key)) {
    this.cache.delete(key);
    this.cache.set(key, value);
    return;
  }
  if (this.cache.size >= this.capacity) {
    const oldestKey = this.cache.keys().next().value;
    this.cache.delete(oldestKey);
  }
  this.cache.set(key, value);
};
```

**注意点：**
1. Map 法是最简洁的实现，利用了 JS Map 的插入顺序特性
2. 另一种方法：哈希表 + 双向链表（更通用，其他语言常用）
3. get 操作也要刷新 recently 度
4. 获取最旧 key：`this.cache.keys().next().value`
5. 同系列：460-LFU缓存（按频率淘汰，更复杂）
